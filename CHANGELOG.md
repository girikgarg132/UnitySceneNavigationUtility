## [1.0.0]

### Added

- File > Open Build Scene and File > Open Scene Selection List submenus, placed directly beneath Unity's File > Open Recent Scene and refreshed automatically.
- Native main-toolbar scene dropdown on Unity 6.3+, excluded from older editor compilation.
- User Preferences page with project-scoped EditorPrefs for startup and return behavior.
- Shareable NavigationSceneList assets and a local list-selection shortcut in the Inspector.
- Single/additive opening, active-scene checks, folder-qualified names, and Project-window pinging.
- Save-cancellation protection and navigation guards during Play Mode, compilation, and asset updates.
- Temporary play-mode startup overrides with session-state recovery and third-party override protection.
- GUID-backed scene-list selection and recent history.
- Bindable scene-menu shortcut without a default conflicting key binding.
- Editor-only assembly definitions and 18 Edit Mode tests.
- Git installation, publishing, compatibility, and release-check documentation.
